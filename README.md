# Musafirah-Women-Carpooling-Mobile-Application
Musafirah is a women-only carpooling app built with Flutter &amp; Firebase, offering safe, verified, and community-based rides. It connects female drivers and passengers through real-time matching, CNIC verification, and location tracking—empowering women’s mobility across Pakistan.
