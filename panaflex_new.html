Musafirah

Women Carpooling Mobile Application

Tech Stack

Flutter
Firebase
OSM / OSRM

Key Features

🛡️

Women-Only Platform

A highly secure and verified ecosystem exclusively designed for female drivers and passengers.

📍

Live Ride Tracking

Real-time high precision GPS tracking to ensure safety and transparency throughout the journey.

🚨

Emergency SOS Alerts

One-tap SOS integration instantly shares live location with predefined emergency contacts.

💰

Automated Fare Calculation

Fair, transparent, and distance-based automated fare estimation using OSRM routing algorithms.

💬

In-App Live Chat

Secure and private real-time communication between the driver and passenger.
